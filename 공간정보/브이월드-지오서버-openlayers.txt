<쉬운 공간 정보 구현 아키텍쳐>

1층, 브이월드: 
	기초 지형도, 지도 타일 이미지 서비스, 국가가 관리

2층, 지오서버: 
	브이월드에서 받은 타일들과, 받은 공간정보로 해당 이미지등의 
	정확한 위치에 공간정보 표시등을 하고, 최종 요청자(브라우저)에게 전달. 

3층, openlayers: 
	사용자측 웹브라우저에서 지오서버가 건네준 최종정보 층에 
	1개층을 더 얹어서 다시 한번 가공해서 보여주는 계층

-------------------
<1층, 브이월드> 

전국의 건물, 도로, 지형은 매일 변하기 때문에 개인이 관리할 수 없습니다. 

그래서 대한민국 국토교통부(브이월드)나 국토지리정보원 같은 국가 기관이 
막대한 예산을 들여 이를 최신화하고 관리합니다.

역할: 
	사용자가 지리적 방향을 잡을 수 있도록 바닥에 깔아주는 지도입니다.

방식: 
	전 세계 도로와 건물을 다 그리려면 컴퓨터가 멈추기 때문에, 
	브이월드는 이를 미리 바둑판 모양의 이미지 조각(Tile)으로 쪼개놓고 
	사용자가 화면을 움직일 때마다 
	조각 이미지만 빠르게 던져줍니다 (WMTS 방식).

-------------------
<2층 지오서버> 

지오서버에 "A대리점은 위도 37.5, 경도 127.0에 있고 작년 매출은 5억 원이다"라는 
위치정보와 A대리점명, 매출액 등을 전달하면, 지오서버는 다음과 같이 작동합니다
	
	- 웹 화면(OpenLayers)이 요청할 때: 
	"그 위치에 맞는 투명한 이미지(PNG)를 그려서 줄까(WMS)? 
	아니면 순수 좌표 데이터로 줄까(WFS)?" 하고 맞춤형으로 데이터를 가공해 쏴줍니다.
	
	- 스타일 입히기 (SLD): 
	"매출 1억 미만은 빨간 점, 5억 이상은 파란 점으로 그려라"라는 규칙을 지오서버에 입력해 두면, 
	지오서버가 알아서 예쁜 지도 레이어로 변환해 줍니다
	
-------------------
<3층 OpenLayers>

OpenLayers (클라이언트 웹 화면 - Web Mapping Library)역할: 
	브라우저 안에서 1층(브이월드 이미지)과 2층(지오서버 이미지)을 
	자석처럼 정확한 좌표에 맞춰 겹쳐서 띄워주는(Rendering) 컨트롤러입니다.
	
	맞춤 기능 구현: 
		사용자가 지도를 클릭했을 때 "여기에 있는 CCTV 정보 팝업창 띄우기", 
		"마우스로 지도 위에 선 그려서 거리 측정하기" 같은 인터랙티브한 기능을 
		JavaScript 코딩으로 넣는 최종 무대입니다.

------------------- 지오서버와 openlayers 관계

지오서버의 지도 타일 이미지위에 공간정보 표시가 가능하고, openlyears 에서도 가능하다.
데이터의 성격에 따라 두 도구(지오서버, openlayers)의 밸런스를 조절하는 것이 GIS 아키텍처의 전부이다.

지오서버 (투박함 + 대용량 성능 우수):
	"데이터가 수만~수십만 개 이상으로 너무 많아서 브라우저가 감당 못 하니, 
	지오서버(서버) 네가 그냥 투박하더라도 하나의 통이미지(PNG)로 구워서 던져줘!" 할 때 씁니다.
	
OpenLayers (세련됨 + 실시간 인터랙티브):
	"데이터가 수백~수천 개 수준으로 가벼우니, 지오서버 너는 순수 좌표 데이터만 보내줘. 
	내가 OpenLayers(브라우저)로 마우스 호버 효과, 애니메이션, 예쁜 커스텀 아이콘 입혀서 
	화려하게 그려낼게!" 할 때 씁니다.
