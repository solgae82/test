
근접분석 

1.밀도분석(커널밀도분석)

	개념
		-주위에 원형 이웃(circular neighborhood)을 그린 후, 
		좌표 위치의 1에서 이웃 경계(neighborhood boundary)
		의 0으로 이동하는 수학 함수를 적용하는 것

		-밀도 계산에서 커널의 크기는 좌표를 중심으로 하는 
		검색 반경(search radius)의 크기에 의해 결정됨

		-검색 반경이 클수록 커널을 평평(flatter)해짐.
		
		-각 좌표에 커널함수를 적용하면, 각 셀의 밀도 값은 셀 중심과 
		중첩되는 모든 커널 표면의 값을 더하여 계산
		
	
	(활용사례) 미세먼지 측정소 적지분석(適地分析)
	
	커널함수 유형
		Uniform
		Triangle
		Epanechnikov
		Quartic
		Triwieght
		Gaussian
		Cosine
		
	QGIS에서 커널밀도분석
		(활용사례) 포인트 데이터로 철새의 이동범위 모델림
		
2.이웃분석(인접성분석)

	개념
		주어진 지점의 주변 셀의 특징을 분석하는 것.
		공간상에서 주어진 지접과 주변의 객체들이 얼마나 가까운가를 파악하는데 활용
		
		인접성의 조건
			-목표지점의 설정
			-목표지점의 근접지역에 대한 명시(거리)
			-근접지역내에서 수행되어야 할 기능의 명시
			(예시)
				-병원으로부터 2km 이내 올 수 있는 고객수

	주요 요소
		거리 측정 방식
			유클리드 거리
			맨하튼 거리
		근접성의 정의(공간가중행렬), (raster 데이터에 주로 사용)
			Rooks Case
			Bishops Case
			Queen's (Kings) case
			
		이동창(Moving window)의 활용
			Neighborhood Operations
			Moving Windows
			(Windows can be any size;
			often odd to provide a center)
			
	인접성분석 유형
		
		(버퍼), 가장 자주 사용되는 유형
			점,선,면 모든 객체로부터 일지ㅓㅇ거리 내의 영역을 표시하는 기능
			버퍼링의 결과는 폴리곤이 됨.
			
		
		티센폴리곤 생성
			입력데이터로부터 일련의 점데이터가 주어졌을때 각 위치에서 
			어떤 값을 할당해야 하는지를 결정할 때 사용.
			
			<들로네 삼감형> => <티센폴리곤>
			
		확산모형
			다양한 현상들을 관심대상인 특정 지점에서부터 거리 증가에 따른 
			누적값 산출 가능.
			(다양한 현상이란 대기, 물, 토양오염, 산에서 물의 흐름, 전파의 확신 등)

			확산을 계산할때 확산을 어렵게 하거나 쉽게 하는 마찰 표면이 있을 수 있음.
			
			확산모형에서 이동은 최소비용경로를 따름.
			
			(동서남북 방향 이동 누적값)
			= 1/2 (출발지점 셀값) + (도착 지점 셀값
			
			(대각선 방향으로의 이동누적값)
			= 1/2(출발지접 셀값) + (도착 지점 셀값) x 루트2
			
		흐름모형
			물의 흐름방향,유역면적, 최장수로의 추출 등과 같은 수문학적 분석에 활용
			
			같은 고도 데이터가 있는 경우 물의 흐름은 래스터의 각 셀에 저장되고,
			가장 경사가 급한 곳으로 흘러가게 되며 물의 방향을 래스터에 저장.
			
			누작흐름도를 계산하면 물이 어떤 방향으로 흐르는지 계산 가능.
		

3.공간추정(보간)

	개념
		제한된 수의 관측값으로부터 관측밧이 없는 지점에 대한 관측값을 추정하는 방법.
		
		샘플 데이터 포인트에서 래스터(raster)의 셀값을 예측
		
		고도,강우,화학 물질 농도 및 소음 수준과 같은 포인트 데이터에 대해 알려지지 않은 값을 
		예측하는데 사용할 수 있음.
		
		
	필요성
		어떤 현상의 높이, 농도 또는 크기를 측정하기 위해 연구 영역의 모든 위치를 방문하는 것은 
		일반적으로 어렵거나 비용이 많이 듦.
		
		대신 전략적으로 분산되 샘플 위치에서 현상을 측정할 수 있으며, 그 측정(관측)값으로 예측값을 구해
		다른 모든 위치에 할당 할 수 있음.
		
		보간의 기초가 되는 가정은 공간적으로 분산된 객체가 [공간적으로 상관] 된다는 것.
		
		공간적 자기상관=공간적 자기회귀
			-공간현상의 위치에 따른 유사성의 정도.
			-가까이 위치하는 것은 유사할 가능성이 크다는 것.
			
		(보간의 사례)
			강우 표면(Rainfall Surface) 보간
			표고 표면(Elevation Surface) 보간
			
	공간추정(보간)의 유형
	
		결정론적 보간법
			확률 이론을 사용하지 않고, 주변 측정값과 결과 표면의 부드러움을 결정하는 
			특정 수학공식에 기초하여 위치에 값을 할당.
			
			보간도구(보간법): 
				역거리가중(Inverse Distance Weighting, IDW)
				최근린 (Natural Neighbor)
				스플라인 (Spline)
				추세 (Trend)
		지형통계적 보간법
			자기 상관(즉저오딘 지점 간의 통계적 관계)을 포함하는 통계 모델을 기반으로 함.
			
			지형통계적 보간법은 예측 표면을 생성할 수 있을 뿐만 아니라,
			예측의 확실성 또는 정확성에 대해서도 일부 척도를 제공함.
			
			보간도구(보간법): 크리깅 (Kriging)
