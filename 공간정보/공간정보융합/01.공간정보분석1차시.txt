1.공간관게
	공간데이터
		실세게의 객체의 모양,속성,위치,관계를 디지털 형태로 저장한 것.
		
	공간데이터 모델
		실세계와 공간데이터를 연결해주는 모델의 유형: 벡터(vector)모델, 래스터(raster)모델
		실세계 객체의 점,선,면 표현
		
		<실세계 공간>
		
		    ↓↓↓
		    
		<공간데이터 모델>
			
			<개념적 모델>
				● 공간사상 유형
				● 공간사상 용어 표준
					
			    ↓↑
			
			<논리적 모델>
				● 0,1,2차 공간객체 유형
				● 백터,래스터 유형
			
			    ↓↑
			
			<논리적 모델>
				● 데이터 파일 포맷
				● 물리적 저장 구조
		<공간데이터 모델>
		
		    ↓↓↓
	
		<GIS 데이터>
		
		
		
		벡터모델 (vector model)
			점,선으로 표현
			
		래스터모델(raster model)
			픽셀
		
	공간데이터 타입
		자주 사용되는 공간데이터 타입: 점,선,면
		공간데이터타입의 정의와 예시
		

		1) point
			정의: 좌표 공간에서 한 지점의 위치를 표시
			예시) 나무 한 구루
			
		2) LineString (Arc)
			정의: 다수의 Point를 연결해주는 선분
			예시) 2호선 신도림역에서 서울대역까지 연결하는 지하철 경로
			
		3) Polygon (area)
			정의: 다수의 선분들이 연결되어 닫혀였는 상태의 다각형
			예시) 호수
			
		4) Multi-point
			정의: 다수 개의 point 집합
			예시) 나무가 모인 군락
			
		5) Multi-LineString
			정의: 다수 개의 LineString 집합
			예시) 지하철 2호선과 지하철 3호선 경로
			
		6) Multi-Polygon
			정의: 다수 개의 Polygon 집합
			예시) 소나무 군락과 참나무 군락
			
		7) GeomCollection
			정의: 모든 공간 데이터들의 집합
			예시) 여러 레이어의 공간 데이터
			
			
	공간관계 유형
		
		두 공간객체 간의 관계를 표현하는 유형.
		실세계 상에서 관찰된 것을 유형화 한 것임.
		공간관계 예)
			- 하나의 레이어에서 두 포인트간의 관계
			- 서로 다른 레이어에서 폴리곤 객체와 point객체의 관계(중첩)
		
		<유형>
		
		- 동등(Equals):
			두 공간객체가 완전히 일치하면 True/false 반환
		
		- 분절(Disjoint): 
			두 공간객체가 겹치는 곳이 없다면 True/false 반환
			
		- 내부(Within): 
			첫번째 객체(A) 가 두번째 객체(B)안에 포함된 경우 True/false 반환
			예) A ⊂ B
			
			A.contains(B): 
				주어인 A가 목적어인 B를 완전히 포함하고 있는지를 확인합니다.
			
		- 포함(Contains):
			두번째 공갼객체(B)가 첫번째 객체(A)안에 포함된 경우 True/false 반환
			예) B ⊂ A
			
			A.within(B): 
				주어인 A가 목적어인 B안에 완전히 포함되어 있는지를 확인합니다
				
		- 교차(Intersect):
			두 공간객체 영역간에 교집합이 존재하는 경우 True/False 반환
			두 도형이 어떤 방식으로든 닿아 있거나 겹치는 것을 의미합니다. (가장 넓은 개념)
		
		- 중첩(Overlap):
			두 공간객체의 영역 중 교집합 영역이 존재하는 경우 True/false 반환
			두 도형의 차원이 같고(중요), 일부만 겹치며, 서로를 완전히 포함하지 않는 상태.
						
		- 접촉(Touch):
			두 공간객체가 경계영역에서만 겹치는 경우 True,
			경계영역 외에서 겹치거나 , 겹치는 곳이 없다면 False 반환
		

2.공간연산

	공간연산의 개념: 두 공간 객체의 연산 결과로 새로운 공간 개체를 반환
	
	
	공간 기하학적 속성 (Spatial Geometric Properties)
	------------------------------------------------------
		  |               공간 연산
	공간데이터타입 --------------------------------------------
		  | 시작점 | 끝점 | 길이 | 중간위치 | 둘레 | 면적 | 중심점
	------------------------------------------------------
	Point     |   ○  |  ○  |  x |   x   |  x  |  x  |  x
	------------------------------------------------------
	LineString|   ○  |  ○  |  ○ |   ○   |  x  |  x  |  x
	------------------------------------------------------
	Polygon   |   ○  |  ○  |  ○ |   ○   |  ○  |  ○  |  ○
	------------------------------------------------------
	
	공간연산 유형:
		- 기본 공간연산 유형:
			교차영역 (Intersection)
			통합 (Union)
			대칭빼기 (Difference)
			엔벨로프 (Envelope)
			시작점 (StartPoint)
			끝점 (EndPoint)
			포인트N (PointN)
			버퍼 (Buffer)
		- 범위 공간연산 유형:
			컨벡스 헐 (Convex Hull)
			컨케이브 헐 (Concave Hull)
			
	공간연산 유형별 정의
		- 교차영역(Intersection):
			교집합인 공간객체를 반환
		- 통합(Union): 
			합집합인 공간객체를 반환
		- 대칭빼기(Diffence):
			차집합인 공간 객체를 반환
		- Envelope:
			공간객체를 포함하는 최소 MBR인 폴리곤 반환
			(MBR: maximum bounding rectangle)
		- 시작점(StartPoing):
			첫번채 Point 반환
		- 끝점(EndPoint): 
			마지막 Point 반환
		- N번째포인트(PointN): 
			N번째 Point 반환
			
		- 컨벡스헐(convex hull):
			포인트들을 포함하는 가장 가장자리 영영을 그리는 포인트를 연결한 폴리곤
			
		- 버퍼(Buffer):
			거리만큼 확장된 공간 객체를 반환
			
	공간연산별 input, output 광간데이터 유형
		----------------------------------------
		             |input 유형   | output 유형  |
		   공간연산     ---------------------------
		             | 점 | 선 | 면 | 점 | 선 | 면 |
		----------------------------------------
		Intersection | - | ○ | ○ | - | ○ | ○ |
		----------------------------------------
		Union        | - | ○ | ○ | - | ○ | ○ |
		----------------------------------------
		Differnce    | - | ○ | ○ | - | ○ | ○ |
		----------------------------------------
		Envelope     | - | ○ | ○ | - | ○ | ○ |
		----------------------------------------
		StartPoint   | - | ○ | ○ | ○ | - | - |
		----------------------------------------		
		EndPoint     | - | ○ | ○ | ○ | - | - |
		----------------------------------------
		PointN       | - | ○ | ○ |숫자 | - | - |
		----------------------------------------
		Convex Hull  | ○ | - | - | - | - | ○ |		
		----------------------------------------
		Buffer       | ○ | ○ | ○ | - | - | ○ |
		----------------------------------------
		
		
3.버퍼(Buffer) 분석
	버퍼의 유형:
		- 버퍼를 위한 기본 input: 
			공간데이터(점,선,면 모두 가능)
			거리(공간데이터로부터 영향 거리)
		
		- 버퍼의 모양에 영향을 미치는 요인: 
			버퍼의 사이드: 한쪽(왼쪽,오른쪽), 양쪽 
			버퍼의 끝모양: 둥근 모양(영향이 있을때), 사각 모양
			
		- 영향면의 독립성(Dissolve):
			- Dissolve None: 각 공간객체의 영향면을 합치지 않음
			- Dissolve All: 각 공간객체의 영향면이 겹치는 영역은 합침.
		
		
	실세계를 반영한 버퍼
		- 인문현상을 반영한 버퍼
			- 시설물의 영향 범위
			- 일정 거리로 영향범위의 쐐기가 만들어짐
		- 자연현상을 반영한 버퍼
			- 자연현상 유출의 범위(홍수)
			- 일반적으로 양방향 버퍼, 둥근 끝모양 버퍼가 만들어짐
