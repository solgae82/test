- 명령줄 한칸 이동
	전진 (오른족 한칸 이동): ctrl + f 
	후진 (왼쪽 한칸 이동): ctrl + b  
	
- 명령줄 처음, 끝 이동
	
	처음 이동 :  ctrl + a
	끝 이동: ctrl + e
	
- 단어 단위 이동
	meta 키란? : ESC , Alt 

	전진: alt + f
	후진: alt + b
	-----------
	전진: ESC 누르고 뗀 뒤 f
	후진: ESC 누르고 뗀 뒤 b
	
- 문자 삭제
	후진 삭제: Backspace
	후진 삭제: ctrl + h
	
	전진 삭제: Delete
	전진 삭제: ctrl + d (아무 것도 없을때 하면, 로그아웃 명령이 됨. 주의!)
	
	후진 단어삭제: ctrl + w
	
- 문자열 자르기 & 붙여넣기
	전진 자르기: ctrl + k
	후진 자르기: ctrl + u
	붙여넣기: ctrl + y
	
- 명령어 히스토리 이동
	이전 명령어 이동: ctrl + p
	다음 명령어 이동: ctrl + n
	
- 명령어 이력 검색 (증분 검색)
	ctrl + r
	
- 화면 표시
	(가끔 잘못 눌러질 경우가 있다, 그럴땐 아래 해제 명령어로 해제)
	잠금: ctrl + s 
	해제: ctrl + q 
	
- 자르기 & 붙여넣기
	커서 위치에서 오른쪽 끝까지 자르기: ctrl + k
	커서 위치에서 왼쪽 끝까지 자르기: crtl + u
	커서 위치에서 자른 글자 붙여넣기: ctrl + y
	
- 현재 프롬프트 빼고 화면 모두 clear
	화면 지우기: ctrl + l (소문자 L)
