파이썬 동시성 용어 정리

	코루틴 → 중단/재개 가능한 작업의 실행 흐름
	await → 코루틴이 멈추고 제어권을 양보할 수 있는 지점
	Task → 코루틴을 이벤트 루프에 올려 독립적으로 진행시키는 단위
	이벤트 루프 → 어느 Task를 다시 실행할지 관리하는 놈

	키워드 async: 
		이 함수는 중간에 멈췄다가 다시 이어서 실행될 수 있는 코루틴 함수다
	
	키워드 await: (러시아 인형 같은 녀석)
		
		await = 그냥 기다린다로만 이해하면 반쪽짜리.
		
		await = 이 작업의 결과를 기다리는데, 
		기다리는 동안 다른 비동기 작업이 실행될 수 있도록 실행권을 양보한다.

		실전에서는 이런 게 await 대상이지.
			response = await API_응답기다리기()
			data = await 네트워크_데이터받기()
			text = await 파일_읽기()

		await asyncio.gather(...)
			gather(...) → 여러 비동기 작업을 함께 진행시키고 하나로 묶는다.
			await        → 그 작업들이 전부 끝날 때까지 현재 코루틴(main)은 기다리며
					(다른 비동기 작업이 실행될 수 있도록 제어권을 양보한다.)
