패킹/언패킹

패킹
- 여러 값을 하나의 묶음으로 만든다.
- 예: a = 1, 2, 3  → tuple

언패킹
- 묶여 있는 값을 풀어서 사용한다.
- 튜플에만 한정된 개념이 아니다.

a, b, c = (1, 2, 3)     # tuple 언패킹
a, b, c = [1, 2, 3]     # list 언패킹

함수 호출 시:
func(*args)              # iterable을 위치 인자로 펼침
func(**kwargs)           # dict를 키워드 인자로 펼침

예:
tasks = [task1, task2, task3]
asyncio.gather(*tasks)
→ asyncio.gather(task1, task2, task3)
