Git은 .gitignore 에 파일, 폴더, 패턴등을 지정하면 버전관리 제외처리를 할 수 있다.

SVN 은 매우 다른 처리 형식을 가지고 있으니, Git과 비슷한 경험으로 하려면 안된다
특히 이클립스를 사용할 경우, 더 헷갈리게 잘못된 정리를 할 수 있으니 주의해야한다.

-------------------SVN 제외 기본

IDE 툴을 사용하지 않는 기본 방식을 이해하는게 도움된다.

SVN은 플젝 디렉토리 root에 아래와 같은 구조를 가진다

	- .svn 폴더와 그 안의 wc.db 데이터베이스
	
	- wc.db 안에 제외할 파일이나 폴더등을 관리한다.
	(SQLite 라는 프로그램 데이터베이스 라고 한다. 
	그래서 찾아보면 SQLite 관리툴로 설정하라는 글도 꽤 있다.)

svn:ignore 라는 속성이 있다.
이게 제외자원을 설정하는 속성인데, 저 속성을 지정하는 곳은 
해당 자원의 부모폴더만 가능하다.

그 설정 내용이 저 위의 wc.db에 저장된다.
이른테면 이렇겠지

	플젝루트/target 디렉토리
	
	target <= svn:ignore 속성 설정됨.
	
	svn:ignore 속성값: a.txt
	
이렇게 되면, 커밋시 /target/a.txt 는 버전관리 대상에서 제외된다.
(근데 이것도 버전관리 대상 이전에 해야하는 것이지, 일단 svn 관리시작되면 제외 안된다)

------------------- 이클립스 svn:ignore 설정

두군데에서 설정할 수 있다. (아직 형상관리 이전이어야 한다.)

실험: /target/a.txt

1. 제외할 폴더,파일 우클릭(a.txt)>Team>Add to svn:ignore
	: 이것도 어느때는 되고 어느 때는 안되고 첨엔 헷갈릴 것이다.
	: 버전관리 시작 전이면 이 메뉴가 활성화되고, 이미 한번 버전관리 되면 비활성화된다.
	(svn:ignore 설정은 target(부모디렉토리)에 설정된다)

2. 등록된 svn:ignore 다시 설정하기(이미 1번으로 등록되어야 볼 수 있다)

	target>우클릭>properties>검색참에 'SVN Info' 검색>리스트 테이블에서 'svn:ignore' 속성 더블클릭>
	Edit Property 창 나오면, Enter a property value: 란에서 추가/수정 가능
	
	또는
	
	target>우클릭>Team>show property>SVN properties창이 뜨고 리스트 테이블에 해당 속성'svn:ignore' 더블클릭'
	> 수정/삭제  가능
	
------------------- 글로벌 속성(전체설정, SVN 1.8이상 가능 )

원래 기본 제외설정은 부모 디렉토리에만 설정할 수 있게 설계되었다고 한다.
근데, 사용자들의 요청 때문인지, svn 1.8 이상부터 글로벌 설정 적용을 추가했나보다

속성명은 아래와 같다

	svn:global-ignores
	
	svn:global-ignores : a.txt (해당 플젝 모든 곳에 a.txt 제외)
	
이클립스라면 SVN플러그인 기준으로 보면된다
내 이클립스는 SVNKit을 사용중이다.

확인: Window>preferneces>Version Control (Team)>SVN>SVN Connector: (SVNKit 1.9.0) 커넥터 버전 확인

(1.8 이상 커넥터이므로 해당 속성을 지원하는 커넥터이다.)


------------------- etc
많은 블로그등에서 이클립스에서 svn 전체설정 제외 가능하다고 나온다.
이 메뉴는 이클립스에서 지원하는 기능으로, Git, SVN등 가리지 않고 이클립스 단에서 제외해주는 통합 기능이다
정확히는 SVN 제외 설정 기능이라고 해서는 안되는 것이다.

	
	Window>preferneces>Version Control (Team)>Ignored Resources 
	
이곳에서는 파일,폴더 및 패턴 지정도 가능하다.
만약 이 이클립스에 여러 플젝 프로그램들(node.js, python, java등) 이 혼재된 상태에서 저 메뉴를 설정하면 대혼란에 빠질 것이다.
(말해 무엇하랴, 겪어봐야 알지)

그러므로 저 메뉴로 전체 설정할때, 딱 1개 프로젝트 관리를 할때만 하는게 좋을 듯 싶다.
