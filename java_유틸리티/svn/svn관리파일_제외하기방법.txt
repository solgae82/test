svn에서 한번 관린된 파일을 제외시키는 것은 어렵다.
(svn:ignore 등록으로 될 것 같지만 안된다.)

svn.ignore은 관리 전에 설정하는 것이다.

이런 사실을 바탕으로 제외 설정 테스트를 해봤다

------------------- 문제 상황 
1. svn에 소스가 관리되고 있고, pc-1, pc-2에 버전관리를 공유하고 있다.
	pc-1은 C드라이브에 설치된 이클립스
	pc-2는 D드라이브에 설치된 이클립스(C드라이브가 용량이 없어서 어쩔 수 없이)
	
2. 같은 플젝소스지만, 드라이브가 달라서 설정이 틀어지는 부분이 발생
: pom.xml 의 폐쇄망 설정 리포지토리 설정에 드라이브 설정이 달라져야 함
	pc-1의 pom.xml: 
		<url>C:\lnxiApp\repository</url>
	pc-1의 pom.xml:
		<url>D:\lnxiApp\repository</url>
		
3. 처음 버전 관리때 제거했으면 좋았겠지만, 나중에 설정한 상태
svn:ignore를 먹여서 커밋 제외가 될듯 하였으나, 커밋에 제외는 되지 않는 상태
(계속 pom.xml 커밋 리스트에 올라옴)

4. 매번 커밋시 인식하고 커밋해야하고 (pom.xml 체크제외), 혹 실수로 커밋 시  
다른 pc에서는 원치 않는 드라이브 설정된 pom.xml 교체 위험성 있음.

------------------- 해결

1. visualSVNServer 에서 플젝 pom.xml 삭제

2. pc-1, pc-2 각 플젝 pom.xml 다른 장소에 백업

3. pc-1, pc-2 SVN update
	: 업데이트 하면 플젝 pom.xml이 삭제된 버전으로 업데이트 된다.
	
4. pc-1, pc-2 플젝에 옮겨 놨던 원본 pom.xml 다시 원위치
	: 새로 등로된 파일이됨.
	
5. pom.xml >우클릭>Team>svn:ignore 를 눌러서 제외 설정
	: 또는 부모폴더 우클릭>properties>SVN Info
		pom.xml
	등록 > apply
	
6. 커밋 시도하면 이제 커밋 리스트에 pom.xml이 뜨지 않는다(제외됨)

현재 상태: 
	버전관리 되지 않는 pom.xml이 pc-1, pc-2에 다르게 설정된 채로 
	존재하게 된다.
