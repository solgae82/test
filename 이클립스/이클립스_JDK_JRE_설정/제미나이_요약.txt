 이클립스 & 자바 빌드·배포 메커니즘 마스터 치트키📌 
 
 Part 1. 이클립스 자바 설정 맵 ("전체 2곳, 프로젝트 3곳")
 
	 이클립스 자바 설정은 이 5가지 메뉴의 먹이사슬 구조만 기억하면 끝납니다. 
	 프로젝트 설정은 항상 전체 설정을 무시하고 덮어씁니다.
	 
 🏢 이클립스 전체 설정 (Preferences) — [2곳]
 
" 내 컴퓨터(Workspace)의 전체 기본 풀(Pool)과 가이드라인을 잡는 곳. "


1. Installed JREs (부품 창고)

	역할: 내 PC에 깔린 진짜 JDK 물리 폴더 경로를 이클립스에 등록하는 곳.
	팁: 
		메뉴 이름은 JRE지만 반드시 JDK 경로를 연결해야 
		컴파일 외 소스코드 보기, 디버깅 등이 정상 작동함.
	
2. Java Compiler (기본 문법 검사관)
	역할: 이클립스 전체의 기본 자바 문법 검사 버전(Compliance Level)을 지정함.
		
		
📦 프로젝트별 설정 (Properties) — [3곳]

"전체 설정을 무시하고 프로젝트 내부에 설정을 강제로 박아두는 곳. 
(설정 파일이 프로젝트 폴더 내에 저장되어 깃 공유 시 타인에게도 강제 적용됨)"


3. Java Build Path ➡️ Libraries 탭 (물리 부품 연결) 
	
	- 정석 세팅: Alternate JRE(특정 폴더 고정) 대신 Execution environment 
	(예: JavaSE-1.8)라는 가상의 표준 규격을 선택해야 함.
	
	- 이유: 구체적인 PC 경로를 박아버리면 타인 PC로 프로젝트를 옮겼을 때 
	자바를 못 찾아 빨간 X가 뜨는 (unbound) 에러의 주범이 됨.
	
	- 참고: 이 선택 박스의 규격 리스트는 내가 설치한 자바가 아니라, 
	내가 다운받은 이클립스 자체 버전이 태어날 때 알고 있던 자바 명단을 따름.

4. Java Compiler (프로젝트 문법 감시관)

	- 핵심 안전장치: 
		[✓] Use compliance from execution environment... 
		체크박스를 무조건 켜야 함.
	
	- 작동 방식: 
		이 체크를 켜면 Build Path 버전(1.8)에 맞춰 컴파일러 문법 버전도 
		알아서 자동 동기화(잠금)됨.
	
	- 비활성화의 비밀: 
		빌드 패스에 특정 폴더(Alternate JRE)를 넣으면 이 체크박스가 해제된 채 얼어붙어 
		수동으로 버전을 골라야 하고, 빌드 패스에 표준 규격(Execution environment)을 
		넣어야만 이 체크박스가 자동으로 켜지면서 안전하게 잠김.
	
5. Project Facets (기술 조합 호환성 검사관)

	- 역할: 
		이 프로젝트가 웹(Dynamic Web Module)인지 단순 자바 프로그램인지 
		성격을 규정하고 웹 서버(Tomcat) 스펙과 자바 버전의 최종 궁합을 감시함. 
		이 셋의 버전이 일치해야 에러가 안 남.

🔄 Order and Export 탭의 진실

	플젝 > properties > Java Build Path > Order and Export
	
	Order (위아래 순서): 
		
		똑같은 이름의 자바 클래스 부품이 충돌할 때, 
		누구 말을 먼저 들을지 결정하는 우선순위 서열.
	
	Export (왼쪽 체크박스): 
		
		내 프로젝트를 다른 프로젝트의 부품으로 끼워 팔 때 JRE 라이브러리까지 
		원플러스원으로 넘겨줄지 결정하는 옵션. 
		
		단독 웹 프로젝트에서는 체크 해제해 두는 것이 완벽한 정석이며, 
		메이븐 빌드 시에는 어차피 무시되므로 안심해도 됨.
		
	[] JRE System Library [JavaSE-1.8]은 체크 해제된 이유: 
		
		내 프로젝트의 본질 유지: 
		
			내 프로젝트는 자바 표준 라이브러리(JRE)를 다른 곳에 파는 
			'도매상(공통 모듈)'이 아니라, 그냥 자바 8 기반으로 돌아가는 하나의 독립된 
			웹 서비스(Application)이기 때문입니다.
		
		이클립스 내부의 평화: 
			
			체크를 해제해 두어야 이클립스 내부에서 혹시 모를 라이브러리 중복 충돌이나 
			꼬임 현상을 원천 차단할 수 있습니다.
