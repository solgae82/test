<폐쇄망 이클립스 네트워크 차단 설정>

Maven 오프라인 설정
	Window>Prefernces>Maven : 
		[v] Offline 체크
		
Window>Preferences>XML (Wild Web Developer):
	: [] Download external resources like referenced DTD, XSD <= 체크 해제
	
	> Validation & Resoulution:
				
		(네트워크 검사 및 유효성 검사는 필요없다! 일때)
		[] Enable validation  <= 체크 해제  
		
		또는 (네트워크 검사 빼고, 유효성 문법 검사 기능은 살리고 싶다)
		
		severity when document has no associated grammar : ignore 변경
		
기본 네트워크 차단 (!!! 이 설정은 왠만하면 하지 말자)
	Window>Preferences>General>Network Connections

		Active Providor: Manual 로 변경
		
		Proxy enties:
		
			HTTP, HTTPS 더블클릭
				Host: 127.0.0.1
				Port: 7777
				
			(가상으로 설정하는 것이다. 저렇게 하면 밖으로 안 나간다고 한다)
			
		Proxy bypass
			localhost, 127.0.0.1 / Manual 만 빼고 모두 삭제
			
	또는
	eclipse.ini 에 직접 박아 넣기
	
	-vmargs 
	..(기존 설정들)..
	
	#윈도우 시스템 프록시 설정을 이클ㄹ립스가 긁어가지 않도록 차단
	-Djava.net.useSystemProxies=false
	
	# 이클립스 코어 파일전송(업데이트 체크등) 네트워크 기능 억제
	-Djava.eclipse.ecf.provider.filetransfer.excludeContributors=true
	-Dorg.eclipse.update.reconcile=false
			
	---------------------
	!!! 주의
	
	이 방법은 극단적으로 모든 네트워크 통신을 안하겠다는 설정이다.
	그러므로 왠만하면 설정하면 안된다.
	
	폐쇄망이더라도, 내부 svn 서버와 통신이 필요할 경우 
	이 설정을 했다면 당연히 알 수 없는 에러가 날것이다.(찾기도 어렵다)
	
	극단적으로 아무런 통신도 필요치 않는 독립접 환경에서만 할 수 있는 설정이다.
	
	이 설정을 했다면 계속 의식하고 있어야 하며,
	이 설정 후 알 수 없는 이상한 오류(플거그인이나 기타 내부 기능들)가 계속 발생한다면, 
	무조건 이 설정을 1차적으로 의심해야한다.
	---------------------

유효성 검사(Validator) 네트워크 차단

	[전체설정]
	Window>Preferences>Validation :
		[v] Suspend all validatros (Validator 모두 차단)

	또는
	
	[프로젝트 설정]
	프로젝트 우클릭>Properties>Validation:
		[v] Suspend all validators 
		또는 
		아래 Validator 선택창에서 맘에 안 드는 녀석만 골라 비활성화 해도 된다.

Oomph 네트워크 접속 skip 설정
	Window>Preferences>Oomph>Setup Taks : 
		[v] Skip automatic task execustion at starup time
