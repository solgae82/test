<파이썬 openCV 와 C++ openCV>

컴퓨터 비전과 딥러닝에서 OpenCV는 파이썬(Python)을 훨씬 더 많이 사용합니다. 
딥러닝 프레임워크(PyTorch, TensorFlow 등)와의 연동성 및 빠른 프로토타이핑 때문이다.

게임 엔진(언리얼의 C++과 블루프린트, 유니티의 C++과 C#)의 구조와 완벽하게 일치합니다.
핵심 로직과 렌더링은 C++이 엔진 밑단에서 처리하고, 개발자는 상위 언어로 편리하게 조작하는 방식입니다.

파이썬 OpenCV의 작동 원리C++ Wrapper: 

	- 파이썬의 cv2 라이브러리는 사실 C++ 코드를 파이썬으로 감싼(Wrapping) 것입니다.
	- 행렬 연산의 비밀: 이미지를 불러오면 파이썬은 이를 C언어 기반으로 작성된 NumPy 배열로 변환합니다.
	- 메모리 공유: 이미지 데이터 자체는 C++이 관리하는 메모리 영역에 두고, 파이썬은 제어권만 가집니다.
	

파이썬(Python)을 사용하는 이유

	1) AI 생태계 통합: 
	PyTorch나 TensorFlow로 딥러닝 모델을 학습시키고, OpenCV로 이미지를 전처리(cv2.dnn 등)하여 
	결합하기에 파이썬이 가장 편리합니다.
	
	2)압도적인 생산성: 
	문법이 간결하여 코드가 짧고, 주피터 노트북(Jupyter Notebook) 등을 통해 
	이미지 결과를 시각적으로 즉시 확인하며 실험할 수 있습니다.
	
	3)내부 C++ 구동: 
	파이썬 OpenCV의 핵심 연산은 내부적으로 최적화된 C++ 코드가 대신 처리하므로, 
	단순 함수 호출 시 속도 차이가 크지 않습니다.
	
C++을 사용하는 경우

	1) 초고속 실시간 처리
	: 자율주행, 임베디드 장치, 로보틱스 등 밀리초(ms) 단위의 지연 시간이나 
	극도의 메모리 관리가 필요한 상용 제품(Production) 단계에서 주로 씁니다.
	
	2) 커스텀 픽셀 연산: 
	파이썬에서 반복문(for)을 돌려 픽셀을 직접 조작하면 속도가 급격히 느려지므로, 
	복잡한 저수준 알고리즘 구현에는 C++이 유리합니다.
