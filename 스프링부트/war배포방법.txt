cp land.war land.war.bak

1. 클래스 배포
	jar uf land.war \
	  WEB-INF/classes/egovframework/land/adm/user/web/UserMngController.class
  
  
2. jsp 배포

	jar uf land.war \
	  WEB-INF/classes/egovframework/land/adm/user/web/UserMngController.class \
	  WEB-INF/classes/egovframework/config/EgovConfigSecurity.class \
	  'WEB-INF/classes/egovframework/config/EgovConfigSecurity$1.class' \
	  WEB-INF/jsp/변경파일.jsp
	  
3. 업데이트 후 검사

	jar tf land.war > /dev/null # 아무것도 안 나오면 검사 성공, 뭔가 나오면 문제
	unzip -t land.war # 압축파일의 모든 엔트리 검사(CRC 검사)
	
	jar tf land.war | grep UserMngController # 클래스가 잘 들어갔는지 확인

4. Servlet JAR 존재 여부 확인

	jar tf land.war | grep -Ei 'servlet-api|tomcat-servlet'
