<도커 이미지 제작>

- Dockerfile은 도커 이미지를 만들기 위한 설계도(Script)입니다
- docker build 명령어를 통해 이 설계도대로 이미지를 자동 생성합니다.


1. 도커 이미지 빌드 기초

	1) Dockerfile 설게도 생성

		$ cd /home/dong

		$ vi ./Dockerfile
		FROM ubuntu:20.04
		:wq

	2) 이미지 빌드 (끝에 현재 디렉토리를 뜻하는 점 '.' 필수)

		$ docker build -t web-server-build .

	3) 생성한 도커 이미지 확인 

		$ docker images
		..
		web-server-build:latest   b02bf99d6aa1        109MB         27.5MB
	
2. [실무] 파이썬 내장 웹 서버 이미지 제작 및 실행

	$ cd /home/dong/docker # 이동
		
	$ vi ./Dockerfile
		FROM ubuntu:20.04
		RUN apt update && apt install -y python3
		WORKDIR /var/www/html
		COPY ["index.html","."]
		CMD ["python3","-u","-m","http.server"]	
	:wq
		-------------
		WORKDIR: 컨테이너 내부의 기본 작업 디렉토리 설정
		COPY: 호스트의 index.html을 컨테이너 내부(.)로 복사
		CMD: 컨테이너 실행 시 파이썬 웹 서버(기본 8000 포트) 자동 구동
		-------------
		
	$ vi ./index.html
		
		<!doctype html>
		<html lang="ko"><head>
		<meta charset="UTF-8">
		<title>파이썬</title>
		</head>
		<body>
			<h1>헤이맨~!</h1>
		</body>
		</html>
	:wq
		
	# 웹 서버 이미지 빌드 
	$ docker build -t web-server-build .
		 
	# 컨테이너 생성 및 실행
	$ docker run --name ws1 -p 8080:8000 -v /home/dong/docker:/var/www/html web-server-build
	
		-------------
		-p 8080:8000: 호스트 8080 포트를 컨테이너 8000 포트와 연결
		-v ...: 호스트 디렉토리를 컨테이너 내부와 동기화(볼륨 마운트)
		-------------
	
	# 서비스 확인
		http://localhost:8080/
		
		#index.html 내용 '헤이맨~!' 출력됨
		
---------etc

볼륨 마운트(-v)의 장점: 
	현재 실행 중인 컨테이너를 바꾸지 않고도, 
	호스트의 /home/dong/docker/index.html 파일 내용을 수정하면 
	브라우저에 실시간으로 반영됩니다. (개발 환경에서 매우 유용)
	
백그라운드 실행: 
	위 실행 명령어에 -d 옵션을 추가하면(docker run -d ...) 
	터미널을 차지하지 않고 백그라운드에서 웹 서버를 계속 띄워둘 수 있습니다.
