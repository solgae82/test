이미지를 tar 묶어 단일 파일로 내보내기를 하고 
다른 도커 시스템에 수동 이미지 등록 가능하다 

	save : 이미지 내보내기
	load : 이미지 등록하기
	
------------------- load

# 기본 복원 명령어 (input 파일 지정)

	docker load -i app.tar

------------------- 빌드 방식별 주의점

1. commit 이미지 ➡️ load 시 주의점

	복원 형태: 
		컨테이너의 특정 시점 스냅샷 상태 그대로 이미지 목록(docker images)에 복원됩니다.
		
	⚠️ 실무 주의점 (환경 변수 및 볼륨 유실): 
		docker commit은 컨테이너 내부의 파일 변경 사항만 저장합니다. 
		컨테이너를 실행할 때 주입했던 환경 변수(-e)나 마운트했던 볼륨(-v) 정보는 이미지에 저장되지 않으므로, 
		load 이후 다시 run할 때 기존 환경 변수와 마운트 설정을 똑같이 직접 입력해 주어야 합니다.
		
		
2. build 이미지 ➡️ load 시 주의점

	복원 형태: 
		Dockerfile 설계도대로 완벽하게 빌드되었던 정식 이미지가 복원됩니다.
	
	⚠️ 실무 주의점 (태그 소실 대처): 
		만약 docker save를 할 때 이미지 이름 대신 이미지 ID(예: b02bf99d6aa1)를 지정해 저장했다면, 
		load했을 때 이름과 태그가 <none>:<none>으로 깨져서 복원됩니다.
		
	해결법: 당황하지 말고 아래 명령어로 이름을 다시 가동해 주면 됩니다.

		docker tag <이미지_ID> web-server-build:latest

3. buildx 이미지 ➡️ load 시 주의점
	
	복원 형태: 
		로컬 도커 엔진 규격에 맞게 변환되어 이미지 목록에 들어옵니다.
		
	⚠️ 실무 주의점 (멀티 아키텍처의 한계): 
		
		buildx는 Intel(x86)과 Apple(ARM) 등 여러 CPU 환경용 이미지를 
		한 번에 묶을 수 있는 강력한 도구입니다. 
		
		하지만 로컬 도커 엔진은 단일 아키텍처 환경입니다.
		
		따라서 여러 플랫폼용으로 묶인 멀티 아키텍처 .tar 파일을 docker load 하면, 
		현재 내 PC의 CPU 레이어와 일치하는 단 하나의 플랫폼 이미지 파트만 추출되어 복원됩니다. 
		(나머지 플랫폼 데이터는 로컬 엔진이 수용하지 못하고 버려집니다.)
		
4. compose 이미지 ➡️ load 시 주의점

	복원 형태: 
		하나의 .tar 안에 묶여 있던 웹 서버(app), DB 등의 여러 이미지들이 한 번에 우르르 복원됩니다.
		
	⚠️ 실무 주의점 (프로젝트 네이밍 규칙): 
		docker compose는 이미지 이름 앞에 자동으로 디렉토리명_을 접두어로 붙여서 이미지를 관리합니다 
		(예: compose-test-db).
	
		다른 서버로 복사해 가서 docker load를 한 뒤 docker compose up을 실행할 때, 
		새로운 서버의 디렉토리명이 다르면 도커 컴포즈가 이미 복원된 이미지를 알아보지 못하고 
		인터넷에서 이미지를 새로 다운받으려고 시도할 수 있습니다.
		
	해결법: 
		새로 복원한 서버에서도 기존과 동일한 이름의 폴더를 만들고 그 안에서 컴포즈 명령을 수행하거나, 
		docker-compose.yml 파일 내에 image: compose-test-db:latest 처럼 
		명확한 이미지 이름을 강제로 지정해 두는 것이 안전합니다.
		
		
	※ 컴포즈의 '디렉토리명 - 접두사' 문제는 compose 명령 실행시 자주 접할 수 밖에 없는 문제다
	(도커/compose/01.compose_네이밍규칠.txt를 참조하라)

💡 4줄 최종 핵심 요약
- commit 복원: 환경 변수와 볼륨은 안 따라오니 다시 run할 때 직접 채워 넣을 것.
- build 복원: 이름이 <none>으로 나오면 docker tag로 이름을 새로 지어줄 것.
- buildx 복원: 내 컴퓨터 CPU 호환 버전 딱 한 종류만 골라져서 복원됨.
- compose 복원: 여러 대가 한 번에 복원되므로, 폴더 이름(프로젝트명) 인식이 꼬이지 않게 주의할 것.
