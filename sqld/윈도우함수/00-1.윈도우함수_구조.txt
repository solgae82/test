2. over 절

over() 내부 옵션 없이 사용
	
	전체 데이터 집합을 기준으로 연산하되, 
	행을 압축(GROUP BY)하지 않고 각 행마다 전체 결과를 보여달라 뜻.

over절 내부 옵션 사용
	
	PARTITION BY와 ORDER BY는 각각 혼자서 사용이 가능합니다. 
	
	하지만 WINDOWING 절은 절대로 혼자 사용할 수 없으며, 
	반드시 ORDER BY와 함께 써야 합니다.

	
	📊 3대 구성 요소 단독 사용 여부 요약

				
	PARTITION BY	
		단독 사용 가능 여부: 가능			
		특징 및 주의사항: 
			집계 함수(SUM, AVG 등)와 궁합이 좋으며, 
			그룹별 총합을 구할 때 씁니다.
		
		(예)
		-- 부서별로 데이터는 나누되, 정렬 없이 부서 전체 합계를 각 행에 출력
		SELECT ENAME, DEPTNO, SAL,
		       SUM(SAL) OVER(PARTITION BY DEPTNO) AS DEPT_TOTAL
		FROM EMP;

		
	ORDER BY
		단독 사용 가능 여부: 가능			
		특징 및 주의사항: 
			순위 함수(RANK, ROW_NUMBER) 등에서 
			전체 데이터 기준으로 순위를 매길 때 필수입니다.
		
		(예)
		-- 1. 순위 매기기 (전체 사원 기준 급여 순위)
		SELECT ENAME, SAL, 
		       ROW_NUMBER() OVER(ORDER BY SAL DESC) AS RK
		FROM EMP;

		-- 2. 누적 합계 (급여가 낮은 사람부터 순서대로 누적해서 더해나감)
		SELECT ENAME, SAL,
		       SUM(SAL) OVER(ORDER BY SAL) AS RUNNING_TOTAL
		FROM EMP;

		
	WINDOWING
		단독 사용 가능 여부: X (불가능)			
		특징 및 주의사항:
			반드시 ORDER BY가 먼저 선언되어야만 뒤에 붙여서 사용.

		(예)
		-- ❌ 에러 발생 (ORDER BY가 없어서 범위를 지정할 수 없음)
		SELECT ENAME, SAL,
		       SUM(SAL) OVER(ROWS BETWEEN 1 PRECEDING AND CURRENT ROW) AS ERR
		FROM EMP;

		-- ⭕ 정상 작동 (ORDER BY 뒤에 WINDOWING 절을 붙여야 함)
		SELECT ENAME, SAL,
		       SUM(SAL) OVER(ORDER BY SAL ROWS BETWEEN 1 PRECEDING AND CURRENT ROW) AS OK
		FROM EMP;

	※ WINDOWING절은 '00-2.windowing절_상세.txt' 에 따로 정리함.
