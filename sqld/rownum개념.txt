
1. 📝 ROWNUM의 정의

ROWNUM은 오라클 데이터베이스에서 쿼리 결과로 나오는 각 행(Row)에 
순차적으로 부여되는 가상 컬럼(Pseudocolumn)입니다.

	• 테이블에 실제로 저장된 데이터(실제 컬럼)가 아닙니다.
	• 쿼리가 실행되는 동안 메모리 상에서 1번부터 시작해 
	데이터가 추출될 때마다 하나씩 증가하며 임시로 부여됩니다.


2. ⚙️ 핵심 작동 원리 (★ 무조건 기억해야 할 순서)

	오라클이 SQL 문을 실행할 때 ROWNUM은 다음 순서로 부여됩니다.
	
	1. FROM 절 + WHERE 절을 만족하는 행을 테이블에서 한 줄씩 가져옵니다.
	2. 가져온 행에 ROWNUM = 1을 임시로 부여합니다(후보번호).
	3. 만약 그 행이 WHERE 절의 ROWNUM 필터 조건에 맞으면 숫자를 확정하고 
		다음 행은 ROWNUM을 2로 증가시킵니다. 
		조건에 맞지 않으면 그 행을 버리고, 다음 행에 다시 ROWNUM = 1을 부여합니다.
	4. SELECT 절을 처리합니다.
	5. ORDER BY 절(정렬)을 가장 마지막에 수행합니다.

3. ⚠️ 실무 시 절대 주의 사항 (치명적인 실수 2가지)


	❌ 주의 사항 1: ROWNUM > 1 이나 ROWNUM = 2는 아무것도 조회되지 않습니다.

		• 이유: 작동 원리 3번 때문입니다. 
		
		첫 번째 행을 가져와 임시로 ROWNUM = 1을 줬는데, 
		조건이 ROWNUM > 1이면 거짓(False)이 되므로 이 행을 버립니다. 
		
		그 후 다음 행을 가져와도 여전히 첫 번째로 살아남은 행이므로 다시 
		ROWNUM = 1이 부여됩니다. 
		
		이 과정이 무한 반복되어 결국 단 하나의 행도 조건에 충족하지 못해 
		조회 결과가 0건이 됩니다.
		
		• 규칙: ROWNUM은 반드시 1부터 시작하는 범위
			(<=, <, = 1)로만 조건을 걸 수 있습니다.

	❌ 주의 사항 2: ROWNUM과 ORDER BY를 동시에 쓰면 순번이 뒤죽박죽 섞입니다.

		• 이유: ROWNUM은 데이터가 추출될 때 이미 번호가 다 매겨지고, 
		그 후에 ORDER BY 정렬이 돌아갑니다.
		
		• 결과: 1~10번까지 번호가 매겨진 상태에서 
		데이터를 뒤섞어 정렬해 버리기 때문에 
		순번이 5, 3, 9, 1... 처럼 엉망이 됩니다.


4. 🛠️ 올바른 사용법 (패턴 가이드)


① 상위 N개 행만 제한해서 가져오기 (Top-N 쿼리)

	가장 안전하고 기본적인 사용법입니다. 
	정렬을 먼저 끝낸 뒤에 ROWNUM을 매겨야 하므로 
	인라인 뷰(서브쿼리)를 반드시 사용해야 합니다. 

	-- ⭕ 올바른 예시: 급여가 높은 상위 5명 조회
	SELECT ROWNUM, emp_list.*
	FROM (
	    SELECT ENAME, SAL 
	    FROM EMP 
	    ORDER BY SAL DESC -- 1. 먼저 정렬을 완료한 서브쿼리를 만든다
	) emp_list
	WHERE ROWNUM <= 5;   -- 2. 바깥에서 ROWNUM으로 잘라낸다


② 게시판 페이징 처리 (예: 11번째부터 20번째 데이터 추출)

	특정 중간 범위를 잘라내고 싶을 때는 
	서브쿼리를 2번 감싸서 ROWNUM에 별칭(Alias)을 부여한 뒤, 
	바깥 쿼리에서 일반 컬럼처럼 조건을 걸어야 합니다.

	-- ⭕ 올바른 페이징 예시 (11등 ~ 20등 조회)
	SELECT *
	FROM (
	    SELECT ROWNUM AS RN, a.* -- 2. 정렬된 데이터에 ROWNUM을 매기고 별칭(RN)을 준다
	    FROM (
		SELECT ENAME, SAL 
		FROM EMP 
		ORDER BY SAL DESC    -- 1. 정렬을 먼저 수행한다
	    ) a
	)
	WHERE RN BETWEEN 11 AND 20;  -- 3. 가상 컬럼이 아닌 '일반 컬럼(RN)'이 되었으므로 범위 조회가 가능하다!


③ 특정 열과 함께 와일드카드(*) 사용 시 주의점

	SELECT ROWNUM, * FROM EMP; 라고 작성하면 오라클 문법 에러가 발생합니다. 
	와일드카드를 함께 쓰려면 테이블명이나 별칭을 명시해야 합니다.

	-- ❌ 에러 발생
	SELECT ROWNUM, * FROM EMP;

	-- ⭕ 정상 작동
	SELECT ROWNUM, EMP.* FROM EMP;

-------------------
where 절의 ROWNUM = 후보번호(임시번호, 1부터 시작, 확정되면 1 증가함)

where ROWNUM <=3 처리 순서

	첫 번째 행: 1 <= 3 → 참 → 1번 확정, 후보번호 증가(2)
	두 번째 행: 2 <= 3 → 참 → 2번 확정, 후보번호 증가(3)
	세 번째 행: 3 <= 3 → 참 → 3번 확정, 후보번호 증가(4)
	네 번째 행: 4 <= 3 → 거짓 → 탈락

where ROWNUM > 1 처리 순서

	첫 번째 행: 1 > 1 → 거짓 → 탈락, 후보번호 (1)
	두 번째 행: 1 > 1 → 거짓 → 탈락, 후보번호 (1)
	세 번째 행: 1 > 1 → 거짓 → 탈락, 후보번호 (1)
	..(끝날때까지 어느 것도 만족하지 않아서 아무 행도 안 나옴)
