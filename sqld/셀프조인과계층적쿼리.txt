셀프조인으로도 1차적 계층적 쿼리를 구현할 수 있다.
복잡한 depth를 사용하게 될때, 계층적 쿼리를 사용하면 된다
-------------------예제

[test4 테이블]
ID	MENU	PARENT_ID
-------------------------
100	가전	(null)
101	냉장고	100
102	세탁기	100
200	문구	(null)
201	볼펜	200


------------------- 계층적 쿼리
select 
   b.*
    
    , level
    ,CONNECT_BY_ROOT menu as root_nm -- 
    ,sys_connect_by_path(menu,'>') as path2
from 
test4 b

-- 순방향
--start with parent_id is null
--connect by prior id=  parent_id

-- 역방향
start with parent_id in (100,200) 
connect by id = prior parent_id
;

-- prior 위치를 잘 살펴보기 바란다
-- 순방향과 역방향 결과를 잘 비교해보라

------------------- 셀프조인 (계층형) 구현
select * from test4 a, test4 b
-- where a.id = b.parent_id; -- 순방향(b.parent_id = a.id 와 같다)
where a.parent_id = b.id; -- 역방향(b.id = a.parent_id 와 같다)
