CUBE, ROLLUP 함수를 이용하면 요약정보라는 표시의 null 표시가 되는데,
이게 요약정보라는 뜻의 null인지, 실제 데이터가 null인지 구분이 가질 않는다.

이럴때 사용하는 함수가 GPOUPING 함수다
SELECT 절에 사용하는 함수다.

컬럼 기준 행이 집계 요약 행이면 1, 일반 행이면 0 을 반환한다

------------------- GROUPING

	GROUPING(컬럼) : 1개만 가능
	
(실전)
	select  
	    dept_name
	    ,job_title
	    ,sum(salary) as hap
	    ,GROUPING(dept_name) as "dept_name요약여부"
	    ,GROUPING(job_title) as "job_title요약여부"
	from gf_employees 
	GROUP BY rollup(dept_name,job_title)
