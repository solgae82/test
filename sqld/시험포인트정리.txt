WHERE , HAVING

	- Group by 없이 Having절 사용 가능.
	(전체 그룹 대상이 됨)

	- WHERE → 원본 행을 모두 제거해도 전체를 대상으로 하는 집계 결과 1행은 생성돼.
		(그룹은 존재한다는 뜻)
		
		COUNT(*) = 0 출력
		
	- HAVING → 집계된 그룹 자체를 탈락시키므로 출력할 행이 없어.
	즉,

	WHERE는 집계할 데이터를 없애고, HAVING은 집계 결과(그룹)를 없앤다.

		-- 결과: COUNT(*) = 0인 행 하나
		SELECT COUNT(*)
		FROM DUAL
		WHERE 1 = 2;

			COUNT(*)
			-------
			0

		-- 결과: 행 자체가 없음 (having 에서 그룹 완전 파괴)
		SELECT COUNT(*)
		FROM DUAL
		HAVING COUNT(*) > 1;
		
count(*) == count(1) == count(23) == count('apple') 모두 같은 뜻.

OFFSET .. FETCH
	
	ORDER BY c1 DESC
	offset 3 rows -- 3행 건너뛰고 4행부터 시작
	fetch (first 또는 next) 5 rows only; -- 5행만 가져오기
	
	(first 또는 next) : 같은 표현이다. 의미 두지 말자
	
	문법	의미
	------------------------
	OFFSET 0 ROWS				건너뛰지 않음
	FETCH FIRST 5 ROWS ONLY			처음 5행
	FETCH NEXT 5 ROWS ONLY			처음 5행 (FIRST와 동일)
	FETCH FIRST 5 ROWS WITH TIES		5번째 행과 정렬값이 같은 행도 포함
	FETCH FIRST 10 PERCENT ROWS ONLY	전체 행의 10% (올림)

	특히 **WITH TIES**가 시험에 나오기 좋아.

	예를 들어 급여가 900, 800, 800, 800, 700이라면:
	- FETCH FIRST 2 ROWS ONLY → 2행
	- FETCH FIRST 2 ROWS WITH TIES → 4행 (800이 동점이므로)
	
	암기 한 줄: 
		OFFSET = 건너뛰기, 
		FETCH = 가져오기, 
		WITH TIES = 동점까지.
