Join 컬럼명이 동일할때, ON 절 대신 USING(컬럴명)을 사용할 수 있다.
	
	A join B USING(id)

A full outer join B
	
	UNION 과 비슷해 보이지만, 같지 않다
	(중복값 없을때는 Union과 같은  결과가 나오지만, 
	중복 값이 있다면 다른 결과가 나온다.)
	
	(정확히는 아래와 같다) 
	LEFT OUTER JOIN (Union All) RIGHT OUTER JOIN에서만 나오는 미매칭 행
	
	SELECT A.ID, B.ID
	FROM A
	LEFT OUTER JOIN B ON A.ID = B.ID

	UNION ALL

	SELECT A.ID, B.ID
	FROM A
	RIGHT OUTER JOIN B ON A.ID = B.ID
	WHERE A.ID IS NULL;

Grouping Sets(A,B)
	
	group by A 결과와 group by B 결과를
	UNION ALL 로 합친 결과와 같다
	
Cross Join
	아래 쿼리는 모두 (카테시안 곱)을 생성한다
	
	select * from A cross join B;
	select * from A, B;

		first/last: 정렬 순서 중 처음 또는 마지막 그룹
		
	:first 설정으로 deptno 오름차순 정렬해서 1위로 나온 그룹(중복이 있을 수 있음)
	중 min(sal)을 반환
	
조인 알고리즘
	Nested Loop Join → 소량 데이터, 인덱스, OLTP
		(한쪽 행마다 다른 쪽을 반복 탐색)
	
	Hash Join → 대량 데이터, 동등 조인
		(해시 테이블을 생성해 매칭)
	
	Sort Merge Join → 정렬 기반 조인
		(양쪽을 조인 키 기준으로 정렬한 후 병합)

셀프 조인 문제는 연결 첫 지점, 끝 지점 파악 -> 컬럼명 확인 순으로 한다.

group by 후 집계함수는 공집합은 '결과없음' 반환
	
group by 없는 집계함수 의 공집합일때 
	count(*)=> 0 , count(sal)=> 0
	sum(sal)=> null
	max(sal)=> null
	min(sal)=> null
	avg(sal)=> null
	
count(*) == count(1) == count(23) 모두 같은 뜻.
