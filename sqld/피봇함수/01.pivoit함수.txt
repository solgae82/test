행을 열로 변환
	: 특정 행 컬럼 '값'들을 새 컬럼들로 변환
	: 동일한 행 다른 컬럼 '수치값'들은 새 컬럼들값으로 집계
집계함수 필수
-------------------
pivot(
	집계함수(집계할 컬럼)
	for 분해할 컬럼명
	in (
		'값1' as 컬럼명1 ,
		'값2' as 컬럼명2 
		, ..
	)
)

: 
1. 특정 행의 특정 컬럼 '카테고리값'들을 새 컬럼명들로 
	추가 변환하고,삭제된다

2. 같은 행의 다른 수치컬럼 '값'은 
	새 컬럼 집계값으로 변환 연속 추가 후 
	수치 컬럼은 삭제된다.

------------------- 테스트 테이블

	select * from tb_pivot;

	nm subject score

	홍길동	math	90

	홍길동	math	100
	홍길동	english	100

------------------- pivot 함수

(실전)
	select * 
	from tb_pivot
	pivot(
	    avg(score)		-- 반드시 집계함수(집계컬럼) 필요
	    for subject in(	-- 분해할 컬럼명(값으로 분해)
		'math' as math, -- 'math'값을 [math]컬럼명으로 생성
		'english' as eng -- 'english'값을 [eng]컬럼명으로 생성
	    )
	)
	;
	
(결과)
	nm math eng
	--------------------
	강감찬	90	95
	홍길동	95	92.5
	이순신	95	100
